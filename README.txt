HUSTLECONNECT SA — PWA STARTER

Upload these individual files to the ROOT of your GitHub repository, replacing the existing index.html:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

On Android: extract this ZIP first, open your repository in Chrome, choose Add file > Upload files, select the individual files, then Commit changes. Do NOT upload the ZIP itself.

After GitHub Pages updates, open the live site in Chrome, tap ⋮ and choose Install app or Add to Home screen (wording may vary).

IMPORTANT: Listing drafts are saved only in the visitor's browser/device. They are NOT shared with other users. To enable public submissions, a secure backend/database, abuse prevention, moderation, and a privacy policy must be added. This is a progressive web app starter, not yet a Play Store app.
